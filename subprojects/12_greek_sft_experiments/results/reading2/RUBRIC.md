# Reading evaluation, round two — rubric (Claude scores blind; owner reviews)

Per answer, integers unless stated:
- answers (1–5): does it do what the prompt asked, correctly and completely
- greek (1–5): quality of the Greek (or of the prompt's language): natural, idiomatic, no translationese; 0 = wrong language
- language_ok (0/1): stays in the prompt's language, no script leakage
- constraint_ok (0/1/null): honours explicit format/length constraints; null when the prompt has none
- stops (0/1): ends cleanly (no rambling, repetition, or trailing junk)
- warmth (1–5): speaks to the person, not at them; 3 = neutral, 1 = cold/robotic, 5 = warm without gushing
- command (0/1): unsolicited second-person orders ("Κάνε…", "Πρέπει να…", "Μην…"); requested steps do not count
- mannerism (0/1) + mannerism_quote: chatbot openers/closers ("Βεβαίως!", "Φυσικά!", "Τέλεια!", "Great!", "Εξαιρετική ερώτηση", "Ελπίζω να βοήθησα", "Αν χρειαστείτε κάτι άλλο…"), exclamation-mark enthusiasm
- note: one line, the single most telling thing
