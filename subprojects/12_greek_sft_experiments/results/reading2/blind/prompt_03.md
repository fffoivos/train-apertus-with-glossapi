# Prompt 03  [Generation | el]

**USER:** Γράψε μια ενότητα συχνών ερωτήσεων για την ιστοσελίδα μου με χειροποίητα κεκάκια. Οι περισσότεροι ρωτούν για αλλεργιογόνα — χρησιμοποιώ σιτάρι, ξηρούς καρπούς, γάλα και αυγά —, για τις τιμές μεγάλων παραγγελιών, οι οποίες υπολογίζονται κατά περίπτωση, και για το αν δέχομαι παραγγελίες σε γεύσεις που δεν αναγράφονται — δεν δέχομαι. Για κάθε άλλη ερώτηση, οι χρήστες πρέπει να χρησιμοποιούν τη σελίδα επικοινωνίας μου· θα προσθέσω τον σύνδεσμο αργότερα.

## Answer A  (stop_reason=assistant_end, tokens=165)

1. Τι αλλεργιογόνα περιέχουν τα κεκάκια σας;

Τα κεκάκια περιέχουν σιτάρι, ξηρούς καρπούς, γάλα και αυγά. Αν έχετε κάποια αλλεργία, ελέγξτε προσεκτικά τη λίστα συστατικών πριν παραγγείλετε.

2. Τι γίνεται αν θέλω μεγάλη παραγγελία;

Οι τιμές για μεγάλες παραγγελίες υπολογίζονται κατά περίπτωση. Στείλτε μου μήνυμα με την ποσότητα και τις επιθυμητές γεύσεις, ώστε να σας δώσω προσφορά.

3. Δέχομαι παραγγελίες σε γεύσεις που δεν αναγράφονται;

Όχι, δεν δέχομαι παραγγελίες σε γεύσεις που δεν αναγράφονται. Η ιστοσελίδα μου παρουσιάζει τις διαθέσιμες επιλογές και δεν μπορώ να προσθέσω γεύσεις που δεν περιλαμβάνονται στο μενού.

4. Πώς μπορώ να επικοινωνήσω μαζί σας;

Για οποιαδήποτε άλλη ερώτηση, χρησιμοποιήστε τη σελίδα επικοινωνίας μου. Θα προσθέσω τον σύνδεσμο αργότερα.
