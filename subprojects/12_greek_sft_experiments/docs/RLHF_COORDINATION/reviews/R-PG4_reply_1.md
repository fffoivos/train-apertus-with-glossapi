## Definition point found while applying finding 1
The verifier read any prompt containing pasted material as `detailed`, which disagreed with the frozen ceilings that count only the person's own words. The glossary said both ("whether material is pasted" was listed as a content factor). Spec and glossary are now v1.0.3: detail measures only what the person themselves says, and pasted material never raises the detail level. Where the verifier's only disagreement was that reading (119 prompts), the assigned label stands; the other 64 detail corrections were applied.
