# Brief: dataset review — greek_if

Greek instruction-following set (data/greek_if/final/greek_if_sft.jsonl, 29,773 rows). Purpose: verifiable Greek IF (40 constraint families = IFEval's + Greek-specific ones: formal plural, no accents, greeklish, Greek caps, ano teleia…), 880 subtopics × 12 request forms, levels 1–5 (25/30/25/12/8% planned; realised Level 5 ≈ 6%), authored requests by Sol, answers verified by the checkers, failures retried once then dropped (2,751 prompts Sol failed twice were dropped — the hard ones). Outcome: IFEval-el +4 (in-family), IFBench-el unchanged (no transfer to unseen constraint types); the pass with the suite pushes IFEval to 71.6. Questions: is the gain worth keeping at this size; what would make IF transfer to unseen constraint types WITHOUT training on IFBench's families (which must stay a pure measure); should difficulty be rebalanced; are the dropped hard prompts a usable pool (e.g. for DPO); which public IF sets in other languages could be adapted (and how to keep Greek-specific constraints).
