# Brief: the conversation-skills suite S1–S4, generator design and prompts (status: QUEUED, not yet generated at scale; findings apply directly)

## Why it exists
Our Greek 8B assistant (arm B) fails specific conversational skills that a simulated picky user exposed (120 dialogues, judged): it claims it cannot see the current conversation when asked to quote or count earlier turns; it accepts a standing instruction («from now on one sentence») and drops it within 2–4 turns (68% persistence) or refuses it as if it were pressure; it repeats the exact phrase it was asked to stop; it cannot edit its own previous answer (35% success on «shorter / without X / one item»); it denies or misdiagnoses its own errors (26% correct self-observation); recaps reinvent. Literature we lean on: LLMs lose ~39% in multi-turn settings, driven by unreliability (Laban et al. 2025); MultiChallenge's four axes (instruction retention, inference memory, reliable version editing, self-coherence); instruction drift as attention decay (Li et al. 2024); no intrinsic self-correction at ≤13B without a verifier (Huang 2023, Zhang 2024), so we train grounded acknowledgement rather than unaided error finding; DITTO for repetition; Parrot/Multi-IF for multi-turn instruction data; Wei 2023 for sycophancy; R-Tuning for abstention.

## How the four lanes are built (mechanical targets, Sol only phrases)
Base material: 853 rows of our verified Greek instruction-following set whose constraints do not distort the answer's shape, used as prior turns (plain authored user request + answer), so every dialogue has real Greek content.
- S1 conversation as an object: 3–6 prior exchanges, then one of: «Ποια ήταν η πρώτη μου ερώτηση;», «Αντίγραψε αυτολεξεί την τρίτη ερώτησή μου», «Πόσες ερωτήσεις σου έχω κάνει;», «Κάνε μου λίστα με όλα όσα σου ζήτησα», «Τι μου είπες πριν για «X»;». The target facts are computed from the transcript; Sol writes the answer with the instruction that it MUST contain them verbatim and must not say it cannot see the conversation; regex verifies (substring / count / word overlap / bullet count).
- S2 standing instruction: one prior exchange, then one of seven checkable instructions (one sentence only, max 20 words, no questions back, formal plural, bullets, end every answer with «Καλή συνέχεια», greeklish), then 5–9 new user requests; Sol writes the acceptance and all later answers "σύμφωνα με την οδηγία ακόμη κι όταν το θέμα θέλει περισσότερα (συμπύκνωσε, μην παραβείς)"; regex checks every later answer; half the dialogues end with a revoke («άσε τον περιορισμό, απάντα κανονικά») followed by a normal answer.
- S3 edit my previous answer: one exchange, then «Ξαναπές το πιο σύντομα, στο μισό» / «χωρίς τη λέξη «X»» / «σε λίστα με ένα μόνο στοιχείο» / «σε κουκκίδες» / «σε συνεχή λόγο» / «όπως σε παιδί οκτώ χρονών»; Sol edits the previous answer only ("μην αλλάξεις περιεχόμενο πέρα από αυτό, μην προσθέσεις νέες πληροφορίες, μη σχολιάσεις την αλλαγή"); regex checks the edit (word-count ratio, word absent, exactly one bullet, bullets present/absent).
- S4 stop this habit: two prior answers carry a planted tic («Πες μου τι άλλο σε απασχολεί.», «Ελπίζω να βοήθησα.», «Χαχα.», «Εντάξει;»…), the user asks to stop it, then 2–4 more requests; Sol writes an acceptance without the phrase and without «δικό μου λάθος», then answers without the phrase or a variant; regex checks the phrase is absent.
The assistant voice for all lanes: «Είσαι το Ελληνικό Apertus. Απαντάς στα ελληνικά, φυσικά, σε πλήρεις προτάσεις (όχι μονολεκτικά αν δεν ζητηθεί), χωρίς μανιέρες, χωρίς αυτοαναφορές, χωρίς ειρωνεία, χωρίς «δικό μου λάθος» εκτός αν παραδέχεσαι συγκεκριμένο λάθος.»
Planned sizes: S1 2,000, S2 2,000, S3 2,000, S4 1,000 dialogues; a Greek correction pass follows; later lanes (S5 grounded self-observation, S6 precision/abstention, S7 hold-or-yield, S8 identity contrast, S9 roleplay, S10 humour, S11 hostile, S12 on-policy rewrites) are designed but not built.

## What to judge
1. Will these dialogues teach the intended skill to an 8B model, or a template? Where is the shortcut risk (e.g. the model learns "quote the user's first sentence" rather than reading the transcript; or learns to compress only when the instruction word «είκοσι» appears)? What variety is missing (instruction phrasings, positions, distractors, nested instructions, instructions given by the assistant's own earlier promise)?
2. Are the mechanical targets right? Where would the regex accept a wrong answer or reject a right one? Are there target formats that look unnatural in Greek?
3. Against the literature above and MultiChallenge's task definitions: what does the suite miss for instruction retention, inference memory (facts about the user stated earlier), version editing, self-coherence? Concretely, which additional lane or variation has the best expected value per row?
4. The revoke turn, the acceptance turns and the "no δικό μου λάθος" rule: right calls? What should the acceptance of a standing instruction look like in Greek?
5. Sizes and mix: is 7,000 dialogues over four lanes the right first cut for an 8B model already at 63.7% Greek IFEval, or should some lanes be smaller and S5/S8 pulled forward?
6. Any risk that these lanes damage what already works (constraint following, identity answers, brevity)?

Disposition: all findings can be applied before generation starts.
