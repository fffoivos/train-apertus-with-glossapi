# Brief: the two PROGRAMMATICALLY SCORED Greek benchmarks we built today — IFBench-el and MATH-500-el (status: BUILT, frozen files; findings change the sets and verifiers before any arm decision)

## What they are for
IFBench-el (300 prompts, 58 held-out verifiable constraint types) tells "follows instructions" from "memorised the 44 constraint families of our Greek IF SFT set"; MATH-500-el (500 problems, levels 1–5) covers the upper half of grade-school→high-school math beside the native lyceum set. Both are scored by code, for comparing SFT arms of an 8B Greek model. Your earlier reviews required: a constraint-id → family mapping with overlap classes reported per prompt; Greek verifier engineering with tests (σ/ς, tonos, question mark, alphabet, syllables); replacement of non-transferable constraints in a separately reported extension; scorer validation against the upstream normaliser before calling math scoring language-neutral; provenance and decontamination records.

## How they were built (data/benchmarks_el/, docs/GREEK_BENCHMARKS_BUILD_20260910.md; ifbench/TRANSFER_ANALYSIS.md)
- IFBench: transfer analysis of all 58 ids → overlap classes seen 2 / seen-in-novel-composition 22 / unseen 31 / unresolved 3 (prompts: 10 / 125 / 153 / 12, 28 mixed); transfer faithful 9 / adapt 47 / replace 2 / exclude 0; deliberate re-tunings (palindrome N 10→3, vowel cap 3→4, repeats floor 5, sentence_alphabet 26→24, reverse_newline 52→14) recorded in RETUNED with reasons. Verifiers: instructions_el.py, 58 classes with the upstream contract, Greek primitives (splitter with both question-mark codepoints, fold, tokeniser, letter sets, stop words, conjunctions, pronouns with a clitic gate, name list with declensions, rule-based syllables, verb-form rule, collation, capitals), 315 tests; documented non-faithful parts: emoji by codepoint ranges, start_verb heuristic, pronoun gate deflates counts, synizesis not modelled, inflection inflates unique-word counts, two upstream bugs not replicated. Prompts: Sol translated the task body with the constraint sentence removed and re-chose English-content kwargs (indeclinable Greek keywords for exact counts, Greek option banks/separators/headers/dates, native reference passages); assembly renders the Greek constraint from the checker's own build_description so wording and verifier cannot drift; kwargs that were the prompt itself (overlap reference text, repeat tasks) take the Greek body with rescaled indices; constraint-only tasks use the description alone. All 300 build and check. Cross-check (Claude Opus, all 300): task ok 295/300, constraint ok 288/300, feasible yes 172 / hard 125 / no 3, naturalness 5: 8 / 4: 222 / 3: 63 / 2: 7; 17 fixes (4 task bodies destroyed by an assembler heuristic, repeat_change duplication, 4 wrong repeat_span index rescalings, a stray separator character, Latin option labels, an infeasible consonant×overlap pair on 3 rows → consonant constraint dropped as a recorded adaptation) plus 12 verifier/description corrections (overlap reference shown, pronoun rule disclosed, repeats floor exposed, thesis/quote_unquote descriptions aligned, EU-27 capitals wording, final-sigma reversal target, case-insensitive option labels, MCQ topic, sentence_type/balance require ≥1 of each type); all applied and re-assembled.
- MATH-500: Sol translated prose only; every LaTeX span, number and [asy] diagram must be byte-identical (prose inside \text{}/\textbf{} and table headers translated; Greek ordinals; «ως κοινό κλάσμα»; «ισοϋπόλοιπο»; question mark outside the span; invented units transliterated). Scorer equiv500 = upstream strip_string normalisation + numeric (decimal comma accepted) + sympy, validated on the 500 reference answers (self 500/500, single-digit perturbation rejected 489/489, format variants). Cross-check 1 (162 rows): the 59-row random sample clean, but 11 of 38 rows repaired by a splice step were corrupt (the span scanner ignored the escaped dollar \$ and re-inserted English prose) and no QC field caught it → scanner fixed, leftover-English detector added, 23 fixes + 49 re-translations; cross-check 2 (72 rows): 3 meaning defects (a diagram deleted, a diagram's coordinates edited, one \text{ if } untranslated), 0 terminology, 10/11 corruptions confirmed repaired → 5 fixes + [asy] byte-equality check; frozen 500/500 (7 by-design LaTeX differences verified). Decontamination: 14 items are template siblings of translated MATH-train rows in our SFT set (same template, different numbers), kept and flagged (denominator 486 without them); IFBench 0 flags.
